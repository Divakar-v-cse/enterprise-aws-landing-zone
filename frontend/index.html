Why there is no IP address here

  • No deployment. No AWS credentials were used and no approval was given.
  • Zero compute. Zero-cost mode sets instance_count = 0, so no instance exists to have an address.
  • Private by design. Even the production profile places instances in private subnets with no public IP, no load balancer and no DNS record.
  • Administrative access is AWS Systems Manager Session Manager, which needs no inbound port and no public address.
  • To obtain a reachable address you would need to add an Application Load Balancer (DNS name) or a Network Load Balancer with an Elastic IP (static IP), both billable and both requiring explicit approval.
